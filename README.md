## ⟢ &nbsp;Mission

<br/>

<table width="82%">
<tr>
<td align="center">
<br/>

I don't think of software as code. I think of it as an experience someone will have —
so I build AI-powered products end to end, from the model doing the thinking
to the pixel doing the talking.

<br/><br/>

Most of my work lives where machine learning meets real interfaces: financial analysis
tools, medical imaging pipelines, detection systems. The AI is only half the job.
The other half is making it feel effortless — clean layouts, honest typography,
interactions that respect the person using them.

<br/><br/>

Away from the editor, I'm behind a camera. Photography taught me framing, patience,
and light — and those instincts quietly shape everything I design. Posters, brands,
event stories, product UIs: it's all the same discipline. Notice more. Show less.

<br/><br/>
