# Profile Setup Guide

Everything you need to take this from files-on-disk to a live, animated GitHub profile.

---

## 1. Create the profile repository (2 min)

GitHub shows a README on your profile only when it lives in a repo **named exactly like your username**.

You already have `Rishi9322/Rishi9322` — this replaces its contents:

```bash
git clone https://github.com/Rishi9322/Rishi9322.git
# copy README.md, SETUP.md and the .github/ folder from this directory into it
git add .
git commit -m "feat: new profile"
git push
```

Works immediately after push (no setup needed):
banner, typing animation, terminal, mission, focus cards, project cards,
timeline, photography grid, skill icons, stats/streak cards, contribution
graph, quote, visitor counter, contact, footer.

---

## 2. Snake animation (2 min)

The snake is generated by `.github/workflows/snake.yml` and published to an `output` branch.

1. Push the repo (the workflow triggers on push to `main`).
2. Or run it manually: **Actions → Generate Snake Animation → Run workflow**.
3. First run creates the `output` branch — the snake appears in the README within ~1 minute.

No tokens needed — it uses the built-in `GITHUB_TOKEN`.

> If Actions are disabled on the repo: **Settings → Actions → General → Allow all actions**,
> and under *Workflow permissions* select **Read and write permissions**.

---

## 3. Metrics (lowlighter/metrics) (5 min)

`metrics.yml` renders `github-metrics.svg` (achievements, repos, stars, languages, calendar, habits, activity, followers).

It needs a Personal Access Token:

1. Go to <https://github.com/settings/tokens> → **Generate new token (classic)**.
2. Scopes: `public_repo` and `read:user`. No expiry (or 1 year).
3. In the `Rishi9322/Rishi9322` repo: **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `METRICS_TOKEN`
   - Value: the token
4. Run **Actions → Generate Metrics → Run workflow**. It commits `github-metrics.svg` to `main` and the README picks it up.

## 4. Spotify — auto-updating now playing (10 min)

There's no `spotify.yml` workflow because the standard approach (novatorem) is a tiny
serverless app on **your** Vercel account, refreshed on every profile view — no cron needed.

1. Fork <https://github.com/novatorem/novatorem>.
2. Create an app at <https://developer.spotify.com/dashboard> → note **Client ID** & **Client Secret**.
   Add `http://localhost:3000/callback` as a Redirect URI.
3. Follow the fork's README to obtain your `SPOTIFY_REFRESH_TOKEN` (one-time OAuth dance).
4. Import the fork into Vercel and set env vars: `SPOTIFY_CLIENT_ID`, `SPOTIFY_SECRET_ID`, `SPOTIFY_REFRESH_TOKEN`.
5. In `README.md`, find the `SPOTIFY` comment block, uncomment it, and replace
   `YOUR-NOVATOREM-APP` with your Vercel deployment name (and `YOUR_SPOTIFY_ID` with your Spotify username).

## 5. WakaTime — coding rhythm (5 min)

1. Create a free account at <https://wakatime.com>.
2. Install the **WakaTime** VS Code extension and paste your API key when prompted.
3. On wakatime.com: **Settings → Profile → check "Display code time publicly"** and
   **"Display languages… publicly"**.
4. Connect your GitHub account on WakaTime (so the username matches `Rishi9322`).
5. In `README.md`, uncomment the `WAKATIME` block.

Stats appear after ~a day of coding activity.

---

## 6. Latest blog posts (2 min, after your portfolio deploys)

`blog.yml` writes your newest posts between the `BLOG-POST-LIST` markers in the README.

1. Deploy your portfolio (it already serves an RSS feed at `/feed.xml`).
2. In `.github/workflows/blog.yml`, replace `https://YOUR-PORTFOLIO-DOMAIN/feed.xml` with the real URL.
3. Run **Actions → Latest Blog Posts → Run workflow** once; then it self-updates twice a day.

---

## 7. Photography grid

The six tiles are styled placeholders. To make them yours:

1. Add your photos to the repo, e.g. `assets/street.jpg` (≈600×400, < 1 MB each).
2. Swap each `placehold.co` URL for `./assets/street.jpg` etc. in the Photography section.

| Banner / typing    | capsule-render + readme-typing-svg | No           |
| Stats / streak     | public image services              | No           |
| Contribution graph | activity-graph service             | No           |
| Skill icons        | skillicons.dev                     | No           |
| Quote / visitors   | public image services              | No           |
| Snake              | `snake.yml` (GITHUB_TOKEN)         | Push once    |
| Metrics            | `metrics.yml`                      | PAT secret   |
| Spotify            | novatorem on your Vercel           | 10 min       |
| WakaTime           | wakatime.com + editor plugin       | 5 min        |
| Blog               | `blog.yml` + your feed URL         | 2 min        |
